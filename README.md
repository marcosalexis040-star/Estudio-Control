# Estudio-Control

Material de estudio para el examen integrador de Ingeniería de Control (sin formulario).

- [`serie-control-sin-formulario/`](serie-control-sin-formulario/README.md): serie de 15 reels verticales que cubren todo el temario (Laplace, primer y segundo orden, plano s, diseño por especificaciones, bloques, Mason, Routh, error en estado estable, PID con Ziegler-Nichols, variables de estado y retroalimentación de estados). Ahora mismo en la **Fase 1: guion y lista de medios**.
